# The shared media library

**Shelves** hold the media (pictures, moving shots, voices, lip-sync clips, finished films). Big files live in the shared OneDrive "Rosling Media Library" or as public links; small reference pictures live here in `cast/`.
**The card catalogue** is `catalogue.json`: one entry per item, saying who is in it, what it shows, its size and quality, what it cost, and whether it is a stand-in or a concept.
**The cast bible** is the `cast` list in the catalogue: Freya, Master Jovi, Sam and Ruby Red, each with reference pictures, a voice and an on-screen label.

Rules: check the library before you make anything new (rule 51). Use cast references so people look the same in every film (rule 52). Add what you make afterwards. Real people only with consent and their real photos (rule 54).

Not built yet: a browsing page that searches and sorts the catalogue by person, category, size and quality. The catalogue format is ready for it.
